# XHS 运行规则（引用自技能主文）

执行后端的选择、通用动作词表和后端专属细则见 `references/xhs-execution-backends.md`。本文件只写与后端无关的页面操作规则。

## 0.1 低消耗与状态确认

- 优先“读取页面”拿结构化字段，减少无意义整页抓取与重复读取。
- 只在关键节点做状态确认：登录确认、到发布页、填写完成、发布前停顿。
- 避免整页长截图（除用户要求归档）；重复操作复用同一标签页。
- 每个动作最多重试 1 次；第二次失败改稳健路径并汇报。
- 记录关键证据：账号名、页面状态、按钮可见、字数等，返回可执行信号。

## 0.2 浏览器稳定规则

- 动作前先确认当前操作的是目标标签页。
- 连续 2 次点击/导航失败后改稳健路径（如直接点击改为“读取页面 + 定位元素”），不做盲重试。
- 登录态失效时停下，请用户自己登录，不代填密码或验证码。

## 3.5 搜索并浏览（核心约束）

1. 仅从搜索结果页点击进入帖子，禁止直接跳转到 `/explore/<id>`。
2. 默认跳过本账号作者内容（避免自刷）。
3. 进入后先校验：不是 404、可见评论/互动信息、可识别标题或作者。
4. 进入方式优先点卡片本体，避免点头像/作者名导致跳错。
5. 若评论控件为 `contenteditable` 或 `p.content-input`，需先触发输入事件再发送。
6. 两条点击失败或 404 后返回搜索页换下一条，不对同链接直跳重试。

## 6.0 回放与降级

- 搜索页结构变化时先做一次状态确认、更新选择器再继续，不盲跑旧路径。
- 关键页（创作页、探索页、用户页）尽量复用已打开标签页。
- 先告诉用户“已达异常节点”，避免继续操作导致误发。
- 发布页关键动作（切 tab、上传、点击发布）失败时：
  1) 先刷新元素引用
  2) 同动作最多再试 1 次
  3) 仍失败则切稳健路径（同义入口 / 用户手动最后一击）
- 轮播详情页抓图时，禁止取第一个 `.img-container`；优先抓取 `.swiper-slide-active:not(.swiper-slide-duplicate) .img-container img`。
- 抓图后核对：URL 末段 key 是否与用户指定封面一致。不一致则重新抓取当前激活图。
- 生成图与参考图过于雷同时，改为只提取抽象风格原则重新生成，不争辩。
- 上传前确认文件路径符合当前后端要求（如 OpenClaw 只接受 `/tmp/openclaw/uploads`）。
