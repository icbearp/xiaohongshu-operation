# 小红书外部来源审计

目标：在采用 X 帖子、网站、GitHub 项目、课程文章、截图或第三方案例之前，先判断“看到了什么、能证明什么、哪些不能用”。热度、收藏量和 GitHub Stars 只能帮助发现线索，不能单独证明方法有效。

## 1. 必须使用的场景

- 用户提供外部 URL、截图、教程或项目，希望整理、改写或发布。
- 研究热门帖子、竞品、行业方法、流量机制或平台规则。
- 内容中包含收入、曝光、转化、效率、算法或合规结论。
- 准备用第三方案例支撑账号服务能力。

## 2. 来源台账 Source Ledger

每个来源至少记录：

| 字段 | 内容 |
|---|---|
| source_url | 原始链接或可追溯位置 |
| author | 作者或组织；未知则写未知 |
| published_at | 发布时间；不可得则写不可得 |
| accessed_at | 本次核验日期 |
| source_type | 官方规则 / 后台数据 / 自有案例 / 开源项目 / 公开样本 / 博主经验 / 课程营销 / 匿名截图 |
| verification_status | 已核验 / 部分核验 / 未核验 |
| commercial_interest | 无明显利益 / 卖课 / 咨询 / 社群 / 软件或 API / 赞助或关联不明 |
| claim | 该来源真正提出的单一主张 |
| evidence_level | A / B / C / D |
| reproducibility | 可复现 / 部分可复现 / 不可复现 |
| decision | ACCEPT / HYPOTHESIS_ONLY / REJECT / UNVERIFIED |
| reason | 为什么采用、降级或淘汰 |

不要把一篇内容的多个结论塞进同一行。一个主张一行，方便逐项判断。

## 3. 证据等级

- **A 级**：小红书官方规则、账号后台数据、真实业务系统记录。可支撑事实，但需保留日期、范围和数据口径。
- **B 级**：可复现的自有案例，包含真实输入、过程、产物、结果与限制。可支撑“本案例中发生了什么”，不能自动推广到所有账号。
- **C 级**：公开竞品样本、开源项目、公开评论需求、可检查的第三方案例。可归纳模式或提出实验假设，不能单独证明因果。
- **D 级**：博主经验、课程文章、营销文案、匿名截图、流量传言。只能作为待验证线索。

使用边界：

- A/B 级可以进入事实段落，但必须注明范围。
- C/D 级只能生成假设，除非得到 A/B 级证据交叉验证。
- 无法打开、无法确认原文、关键内容在付费墙后或无法追溯时，标为 `未核验` 和 `UNVERIFIED`，不得进入最终事实结论。

## 4. 商业利益检查

逐项检查：

- 作者是否销售课程、社群、咨询、API、软件或代运营。
- 是否以收入承诺、焦虑、限时、名额或私域联系方式收尾。
- 推荐对象与作者是否存在赞助、分成或关联关系。
- 免费内容是否故意缺失关键步骤，并把付费产品写成唯一答案。

商业利益不自动等于无效，但会降低独立性。有关联时，核心主张必须找到独立证据或降级为 `HYPOTHESIS_ONLY`。

## 5. 强制淘汰

出现下列任一项，相关主张进入 `Rejected Claims`，默认不生成成稿：

1. 无证据的收入、涨粉、曝光、成交或效率保证。
2. 没有官方来源或自有数据支持的算法公式、权重、流量池数字和养号分数。
3. 未经授权的搬运、洗稿、去水印再发布或近似性过高的仿制。
4. 用谐音、暗号、主页信息等方式规避站外导流治理。
5. 虚构身份、履历、客户案例、收益、评价或前后对比。
6. 只有工具名和功能罗列，没有真实任务、过程、判断、产物和限制。
7. 把生成内容伪装成真人亲历，或提供规避 AI 标识的方法。
8. 把付费课程销售页或营销文章当作唯一方法论来源。

## 6. 决策规则

- `ACCEPT`：来源已核验，主张与证据匹配，可在限定范围内使用。
- `HYPOTHESIS_ONLY`：有启发但不能证明，应转为实验或待验证问题。
- `REJECT`：触发强制淘汰，或主张与证据明显不匹配。
- `UNVERIFIED`：无法确认原文、身份、日期、数据或上下文。

不要因为内容热门就上调证据等级，也不要因为来自 GitHub 就默认安全或有效。

## 7. 标准输出

```md
## Source Ledger
| 来源 | 核验状态 | 商业利益 | 主张 | 等级 | 可复现性 | 决策 | 原因 |

## Accepted Insights
- 可采用结论：
- 适用范围：
- 证据：

## Rejected Claims
- 被删除主张：
- 触发规则：

## Missing Evidence
- 缺少什么：
- 如何补证据：
- 补齐前允许做什么：仅形成假设 / 暂停创作
```

## 8. 降级策略

- 来源打不开：请求原文或截图，同时继续寻找官方或独立来源；不得猜测正文。
- 数据口径不明：描述“公开可见互动”，不写曝光率、点击率或成交率。
- 案例不可复现：保留问题或结构启发，删除效果承诺。
- 多个来源互相引用：追溯最初来源，不能把相互转述当成多重证据。
